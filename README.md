# 🎓 QA101 — n8n Quickstart

> ✨ Overview
> Dokumentasi pembelajaran **n8n Quickstart** dari *n8n Academy* yang merangkum fundamental hingga implementasi workflow automation menggunakan n8n.
>
> Materi mencakup perancangan workflow, pengelolaan dan manipulasi data, integrasi layanan eksternal, hingga pengembangan **AI Agent** yang dilengkapi memory dan tools.
>
> **Learning Path:** Workflow Fundamentals → Data Processing → AI Agent Development

---

## 🗺️ Learning Roadmap

| Section | Learning Focus | Units |
|:--|:--|:--:|
| 🟦 **PART 01** | Getting Started — Workflow, Data Table, Filter, Code, Discord, Scheduling, Publishing, Export & Import | **01–10** |
| 🟪 **PART 02** | Working with Data — Data Structure, HTML/XML, Date & Time, Binary Data, Split, Merge, Looping, Debugging & Error Handling | **01–12** |
| 🟩 **PART 03** | Building an AI Agent — Memory, Tools, System Prompt, Agent Configuration & Testing | **01–11** |

## 📚 Course Contents

### 🟦 PART 01 — Getting Started
*Fundamental concepts and essential workflow operations.*

Mempelajari dasar penggunaan n8n, mulai dari membuat workflow hingga mengelola proses automation.

- Workflow Design & Fundamentals
- Data Table Management
- Filtering & Data Manipulation
- Edit Fields Node
- Code Node Fundamentals
- Discord Integration
- Schedule Trigger
- Workflow Publishing
- Export & Import Workflow

### 🟪 PART 02 — Working with Data
*Understanding, transforming, and managing workflow data.*

Mendalami cara kerja data di dalam n8n, termasuk transformasi berbagai format data, penggabungan informasi, serta penanganan error.

- Understanding Data Structure
- Working with HTML & XML
- Date & Time Manipulation
- Binary Data Processing
- Splitting Data
- Merging Data
- Looping & Iteration
- Workflow Debugging
- Error Handling
- Practical Exercises

### 🟩 PART 03 — Building an AI Agent
*Developing intelligent automation with AI capabilities.*

Mempelajari cara membangun AI Agent yang dapat memahami instruksi, mempertahankan konteks percakapan, dan menjalankan fungsi melalui tools.

- Introduction to AI Agent
- Understanding AI Agent Workflow
- Memory & Context Management
- Simple Memory Integration
- AI Agent Tools
- Tool Configuration
- System Prompt Engineering
- Agent Behavior & Instructions
- Testing & Evaluation
